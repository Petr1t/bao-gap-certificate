# AGENTS.md

## Purpose

A public extract of one program: the fail-closed verifier for exact rational
optimality-gap certificates of a radiotherapy beam-angle research model, plus
its tests and a synthetic example. It is a read-only artifact of a larger,
private study. See `PROVENANCE.md` for what came from where.

## Rules

* **The verifier stays fail-closed.** Every check aborts on the first failure.
  Never add a tolerance, a fallback, a "best effort" path, a default for a
  missing field, or an exception that is swallowed. A check that cannot be
  performed is a failure, not a pass.
* **The verifier imports no producer code.** It recomputes everything from the
  sealed bytes. Do not introduce a dependency on any solver, model builder or
  study orchestration.
* **No patient data.** No `.h5`/`.mat` dose-influence matrices, no model
  packets, no certificates derived from real patients, no cohort results. The
  only data in this repository is generated by
  `examples/build_synthetic_example.py`, and it is generated, not committed.
* **No host coupling.** No absolute paths into a machine, no user names, no
  accounts, no hosts, no secrets.
* **Changes to `portpy_cohort_check.py` change the meaning of every
  certificate it has ever accepted.** Treat it as frozen: if it must change,
  record the change and its reason in `PROVENANCE.md` in the same commit.
* Claims that are unreviewed or work in progress upstream are marked as such
  here too. Do not promote them by rewording.

## Working on it

```
python -m pytest tests/ -q
python examples/build_synthetic_example.py --out example
python portpy_cohort_check.py --model example/model --source example/source \
       --certificate example/model/certificate.json --report example/report.json
```

The whole suite runs in a few seconds and needs no solver and no network.
